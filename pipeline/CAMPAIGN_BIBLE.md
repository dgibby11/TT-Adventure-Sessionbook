# Campaign Bible — [CONCEPT PENDING]

**STATUS: awaiting human approval of a concept.** Nothing past Phase 0 may
happen until this file has been edited by the DM to replace this notice with
an approved concept.

## How this gets filled in
1. Iteration 1 of the pipeline writes 2-3 concept pitches to
   `pipeline/CONCEPT_PITCHES.md` and halts (writes `pipeline/STOP`).
2. The DM reviews the pitches in that file, picks one (or asks for a redo by
   deleting `pipeline/STOP` and leaving this file untouched — the next
   iteration will just draft new pitches again), and edits **this file**,
   replacing this entire notice with the chosen concept: title, premise,
   tone, factions, central mystery, level arc.
3. The DM deletes `pipeline/STOP`.
4. The next iteration reads this file, sees a real concept instead of the
   placeholder, and expands it into the full bible in place (regions/
   geography, detailed faction goals, session/arc skeleton, naming
   conventions) before any entity content gets created. See
   `pipeline/RUN_PROTOCOL.md` Step 4b.

## Schema reference
Do not duplicate or fork the entity schema here — it lives in root
`CLAUDE.md` under "Data Model — Entities" and is locked. This file is for
narrative/creative canon only: setting, tone, plot, factions, naming
conventions, and anything else an author would want fixed in advance so
hundreds of later entities stay consistent with each other.
