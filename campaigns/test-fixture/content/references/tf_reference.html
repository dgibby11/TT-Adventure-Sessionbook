Fixture Overview

REFERENCE · Fixture Docs

This campaign exists solely to be driven by .claude/skills/run-tt-adventure-sessionbook/driver.py. It is hidden from the campaign picker ("hidden": true in campaigns/index.json) and is not real campaign content.

What it deliberately contains

  • One entity of every type: location, npc, faction, item, creature, mystery, session, reference.
  • A session in category Planning with a populated reveals[], so the Complete-Session dialog is reachable.
  • A dm-only entity ([[tf_mystery]]) and .dm-only blocks, for the view toggle.
  • External links[] on [[tf_creature]], for the modal's References section.

If you are reading this in the app, you deep-linked to the fixture campaign. Go back to [[tf_root]] or return to the launcher.
