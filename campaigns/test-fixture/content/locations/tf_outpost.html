The Far Outpost

LOCATION · Fixture Outlands

The hub of the fixture campaign's second region, listed in campaign.json → regions with the label The Far Side. It exists so the Regions home view has more than one column, and so there is somewhere for the party to go that is not [[tf_root]].

What hangs off it

  • [[tf_camp]] — a sub-location, one link from this hub.
  • [[tf_hall]] — a link across regions. The Hall is equally near both hubs, so it must stay in the first region and must not be listed in this one's column.

DM Only

Also links [[tf_vault]], a dm-only location. It appears in this region's column in DM view and nowhere in Player View.
